# TFM_NS5A_HCV1a
Analisis filogenetico y estructural de mutaciones de resistencia en NS5A del HCV genotipo 1a
Este repositorio contiene el análisis computacional desarrollado para mi Trabajo Fin de Máster (TFM) en Bioinformática, centrado en la identificación, caracterización y evaluación estructural de mutaciones de resistencia (RAS) en la proteína NS5A del virus de la hepatitis C (HCV), genotipo 1a.

El objetivo principal es integrar datos de secuencias, análisis evolutivo, métricas de variabilidad y modelado estructural para comprender el impacto funcional de las RAS en la respuesta a antivirales.
